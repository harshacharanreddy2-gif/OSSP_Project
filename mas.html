How each part of the C code works

Agent processfork() then exec("/proc/self/exe", "--agent"): the same binary restarts as a separate process.
CPU slotsA counting semaphore starting at 3. The scheduler waits on it before each fork; the SIGCHLD handler posts it back.
Memory framesA POSIX shared-memory table with a process-shared mutex and condition variable. An agent waits for free frames (a simulated page fault).
Task hand-offAn anonymous pipe on fd 3 carries the task from the scheduler to the new agent.
ResultsAgents append to a log, write fixed-size records with lseek(), and report through a FIFO.
Live statusA UNIX socket answers ./mas --status from a second terminal.
